# Changelog

All notable changes to The Proposal Field Guide will be documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] — 2026-05-07

### Initial release

First public version of The Proposal Field Guide.

Includes:

- Ten chapters covering the federal proposal lifecycle from capture through debrief
- Working appendix with compliance matrix template, win theme worksheet, and Pink/Red/White Glove review checklists
- Federal acquisition glossary
- Chapter on AI use in proposal writing, with vocabulary fingerprint and editing pass guidance

### Planned for future releases

- Accessible PDF version produced from InDesign layout
- Expanded graphics with diagrams for the lifecycle, color team timing, and win theme structure
- Additional appendix templates based on reader feedback
